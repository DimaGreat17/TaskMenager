# Восстановление доступа к администратору

Если `npm run db:seed:local -w @taskboard/api` выводит `Admin exists; not changing password`, пользователь уже создан. Повторный запуск seed не меняет пароль.

Для локального сброса учётной записи суперадминистратора запустите из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\reset-admin-local.ps1
```

Введите новый пароль длиной от 12 символов. Пароль не будет выведен на экран, записан в историю команд или в .env. Утилита обновит хеш в базе данных для логина из `ADMIN_USERNAME` (по умолчанию `admin`) и отзовёт старые сессии.

Понадобится работающая PostgreSQL, настроенная `apps/api/.env` и уже выполненная генерация Prisma client. Утилиту следует запускать только на доверенном компьютере с доступом к базе данных. Не используйте её для сброса чужих аккаунтов без разрешения администратора.

Изменение `ADMIN_PASSWORD` в файле `.env` само по себе **не** меняет существующий пароль.
