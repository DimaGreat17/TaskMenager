# Визуальная доска: инструменты и горячие клавиши

Редактор является частью проекта. Изменения сохраняются в PostgreSQL через `PUT /api/v1/boards/:id/canvas` с проверкой версии доски, поэтому при конфликте изменений редактор выдаст предупреждение и обновит полотно.

## Инструменты

- Выделение: нажмите блок или выделите несколько рамкой; Shift позволяет выбирать несколько блоков.
- Перемещение: перетащите отдельный блок. Если перетащить рамку группы, переместятся и все вложенные в неё блоки.
- Создание стрелки: включите режим связей и протяните от соединительной точки одного блока к другому.
- Создание: панель инструментов содержит заметку, текст, фигуру и связанную задачу.
- Группировка: выберите два и более негруппированных блока, нажмите кнопку группы. Для разгруппировки выберите рамку группы.
- Контекстное меню: правый клик по блоку или пустой области.
- Масштаб: кнопки +/−, Fit View, колесо мыши.
- Мини-карта помогает ориентироваться на большом полотне.

## Клавиатура

| Клавиши | Действие |
|---|---|
| Ctrl+C | Копировать выделенные блоки внутри редактора |
| Ctrl+V | Вставить копию |
| Ctrl+D | Дублировать |
| Ctrl+G | Сгруппировать |
| Ctrl+Shift+G | Разгруппировать |
| Ctrl+Z | Отмена |
| Ctrl+Y / Ctrl+Shift+Z | Повтор |
| Delete | Удалить выделение |
| Enter | Редактировать выбранный блок |
| Escape | Сбросить выделение |

Снимки истории отмены хранятся только во вкладке браузера до обновления страницы (до 50 последних операций). Копирование относится к внутреннему буферу доски и не заменяет системный буфер Windows.

## Ограничения

В версии MVP отсутствуют совместные курсоры и CRDT. При одновременном редактировании редактор обнаруживает изменение версии и просит повторить действие. Это исключает молчаливую перезапись целой доски, но может приводить к необходимости повторного редактирования.

Группы сохраняются как отдельные рамки с привязкой блоков `groupId`. Пока не реализованы вложенные группы и изменение размеров групп мышью.

## После обновления из GitHub

Из корня репозитория выполните `powershell -ExecutionPolicy Bypass -File .\\scripts\\setup-local.ps1`, чтобы применить миграцию `20261109090000_canvas_editor`, затем запустите `scripts/start-local.ps1`.

Перед обновлением с важными данными рекомендуется сделать резервную копию PostgreSQL.
